# Victoria 简体中文语言包（Chinese.lng）

为 Windows 磁盘检测 / 坏道扫描工具 **Victoria**（作者 Sergey Kazansky，官方站 hdd.by）提供**官方外挂式中文界面**。

- ✅ **不改 exe、非第三方汉化版**：只放一个文本语言文件，零捆绑风险
- ✅ **单一文件兼容 5.23 与 5.37**：已合并两版字符串，自动适配
- ✅ 译文覆盖率 100%（技术符号如 `1234` / `PIO` / `HPA` 按官方惯例原样保留）

> ⚠️ 非官方粉丝翻译，与 Victoria 作者及 hdd.by 无任何隶属关系。权利声明见 [NOTICE](NOTICE.md)。

## 支持的版本

| 版本 | 状态 |
|---|---|
| Victoria 5.23 | ✅ 已验证（你正在用的版本；USB / 硬盘盒场景建议用此版） |
| Victoria 5.37 | ✅ 已验证（注意：5.37 扫 USB 盘可能掉线，故 USB 场景建议用 5.23） |

## 安装（3 步）

1. 下载本仓库的 `Chinese.lng`
2. 复制到 Victoria 程序目录下的 `LNG\` 文件夹（与 `English.lng` 并列）
3. **以管理员身份**运行 Victoria → 菜单 **Language → Chinese**

> 💡 装好后需**重新选一次语言**：加入新 `.lng` 后 ini 内的语言索引会移位。

## 已知限制

- 中文模式下按 **F1 暂无中文帮助**（`Help\Chinese\` 不存在）；界面已全中文化，不影响使用。帮助中文化属 phase 2。
- 用 **5.23** 加载时，日志可能提示缺少若干字符串（5.37 新增键），属正常、不影响功能。
- 菜单中显示的语言项名为文件名 `Chinese`（ASCII 文件名兼容性最佳）。
- 本包仅做界面本地化；**Write / Erase / Remap 会破坏数据**，动手前务必先备份。
